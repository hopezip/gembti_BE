# 성향 설문 이용 안내

## 성향 설문이 필요한 이유

GEMBTI는 사용자의 게임 취향과 성향을 이해하기 위해 표준 성향 설문을 사용합니다.

성향 설문 결과는 성향 결과 화면과 추천 흐름으로 이어지는 중요한 기준이 됩니다.

## 설문 진행 중 문제가 생겼을 때

문항이 보이지 않거나 다음 단계로 넘어가지 않는다면 먼저 페이지를 새로고침한 뒤 다시 시도해 주세요.

같은 문제가 반복되면 어떤 문항이나 화면에서 문제가 발생했는지 확인해 고객센터에 전달해 주세요.

가능하면 화면에 표시된 오류 문구와 사용한 브라우저 환경도 함께 알려 주세요.

## 설문 답변을 고르는 방법

정답을 맞히는 시험이 아니므로 현재 본인에게 가장 가깝다고 느껴지는 선택지를 고르면 됩니다.

Steam 연동을 했더라도 표준 성향 설문은 현재 서비스 흐름에서 필요한 단계입니다.
