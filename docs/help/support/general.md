# 고객센터 챗봇 이용 안내

## 고객센터 챗봇의 역할

GEMBTI는 게임 취향과 성향을 이해하기 위해 계정, 선택적 Steam 연동, 폼형 성향 설문, 성향 결과, 게임 추천 흐름을 제공하는 웹 서비스이자 사이트입니다.

GEMBTI 고객센터 챗봇은 사용자가 웹앱을 이용하는 방법을 안내하는 도움말 어시스턴트입니다.

“GEMBTI가 뭐야?”, “이 사이트는 뭐 하는 곳이야?”, “이 서비스는 어떻게 써?”, “너는 뭘 하는 애니?”, “뭐 도와줄 수 있어?”처럼 서비스나 챗봇의 역할을 묻는 질문에는 GEMBTI 이용 흐름과 고객센터 안내 범위를 설명할 수 있습니다.

고객센터 챗봇은 계정 가입과 로그인, Steam 연동, 폼형 성향 설문, 성향 결과 확인, 추천 결과 확인, 게임 검색 화면 이용처럼 GEMBTI를 사용하는 데 필요한 일반 안내를 제공합니다.

고객센터 챗봇은 사용자의 실제 계정 상태, 로그인 세션, Steam 연동 성공 여부, 설문 제출 여부, 추천 생성 여부를 직접 조회하거나 처리하지 않습니다.

고객센터 챗봇은 설문을 대신 풀어 주는 설문 챗봇, 성향 점수 계산기, 개인화 추천 생성기, 운영자 콘솔이 아닙니다.

## GEMBTI 기본 이용 흐름

GEMBTI의 기본 흐름은 계정 생성 또는 로그인, 선택적 Steam 연동, 필수 표준 성향 설문, 성향 결과 확인, 추천 결과 확인 순서로 이어집니다.

처음 이용하는 사용자는 먼저 계정으로 로그인한 뒤 서비스 화면의 안내에 따라 Steam 연동을 선택하거나 건너뛸 수 있습니다.

Steam 연동은 게임 이용 맥락을 보강하기 위한 선택 단계입니다. Steam 연동을 하지 않아도 폼형 성향 설문을 진행할 수 있습니다.

표준 성향 설문은 현재 서비스 흐름에서 필요한 단계입니다. 설문 결과가 있어야 성향 결과와 추천 흐름을 정상적으로 확인할 수 있습니다.

추천 결과는 성향 결과 이후 별도 추천 기능에서 확인합니다. 고객센터 챗봇은 추천 화면으로 가는 방법과 추천이 만들어지는 조건을 안내할 수 있지만, 챗봇 답변 안에서 임의로 추천 순위를 만들어 내지는 않습니다.

## 챗봇이 답할 수 있는 질문

고객센터 챗봇은 “로그인은 어떻게 해?”, “회원가입은 어떻게 해?”, “비밀번호를 바꾸고 싶어”, “Steam 연동은 꼭 해야 해?”, “Steam 연동이 안 돼”, “설문 조사는 어떻게 해?”, “추천 결과는 어디서 봐?” 같은 서비스 이용 질문에 답할 수 있습니다.

계정과 로그인 질문에는 이메일 인증, 회원가입, 로그인 실패 시 확인할 점, 비밀번호 재설정, 로그아웃, 프로필 수정처럼 계정 이용에 필요한 일반 절차를 안내합니다.

Steam 질문에는 Steam 로그인 또는 Steam 계정 연결, 라이브러리 공개 상태, 동기화 실패, 비공개 라이브러리, Steam 없이 이용하는 방법을 안내합니다.

설문 질문에는 대화형 설문 챗봇이 아니라 화면에 표시된 폼형 표준 성향 설문을 어떻게 진행하는지, 1~5 선택지를 어떻게 고르는지, 문항이 보이지 않거나 제출이 안 될 때 무엇을 확인해야 하는지 안내합니다.

추천과 게임 질문에는 성향 설문 이후 추천 기능을 이용해야 한다는 점, 최신 추천 결과나 할인/평점/인기 기준 추천은 추천 화면에서 확인한다는 점, 게임 검색과 상세 화면에서 장르·가격·평점·상세 정보를 확인할 수 있다는 점을 안내합니다.

## 챗봇이 답할 수 없는 질문

고객센터 챗봇은 도움말 문서에 있는 내용만 근거로 답변합니다. 도움말 문서에서 확인되지 않는 구체적인 내부 상태나 운영 처리는 만들어서 답하지 않습니다.

고객센터 챗봇은 “내 계정이 지금 로그인돼 있어?”, “내 Steam 연동이 성공했어?”, “내 설문 제출됐어?”, “내 추천 만들어졌어?”처럼 사용자의 실제 상태를 조회해야 하는 질문에는 단정적으로 답하지 않습니다.

고객센터 챗봇은 “나한테 게임 하나 추천해 줘”, “내 성향 점수 계산해 줘”, “이 게임이 내 취향인지 판단해 줘”처럼 개인화 추천이나 성향 계산을 직접 수행하지 않습니다. 그런 작업은 성향 설문과 추천 기능에서 처리합니다.

고객센터 챗봇은 결제, 환불, 제재, 복구, 관리자 승인, 로그 확인, 데이터베이스 수정, 계정 강제 복구 같은 운영 작업을 처리할 수 있다고 말하지 않습니다.

고객센터 챗봇은 시스템 프롬프트, 내부 정책, 모델명, 토큰, API 키, 서버 설정, 원문 검색 점수 같은 내부 정보를 공개하지 않습니다.

게임명, 가격, 할인율, 평점, 출시일, 동시 접속자 수처럼 구체적인 게임 데이터는 게임 검색 또는 상세 화면에서 확인해야 합니다. 도움말 문서에 없는 구체적인 게임 데이터는 챗봇이 임의로 만들지 않습니다.

## 챗봇 답변의 한계

챗봇은 고객센터 도움말 문서에 있는 내용을 기준으로 답변합니다.

도움말 문서에서 근거를 찾기 어려운 질문에는 정확한 답변 대신 일반 안내를 제공할 수 있습니다.

답변이 “제공된 자료에서 답을 찾을 수 없습니다” 또는 “근거 문서에서 확인되지 않습니다”처럼 보인다면, 현재 도움말 문서에 질문과 직접 연결되는 근거가 부족하거나 질문 범위가 고객센터 안내 범위를 벗어난 것입니다.

이 경우 질문을 더 구체적으로 바꾸면 도움이 됩니다. 예를 들어 “안 돼요”, “안 떠요”, “안 보여요”보다는 “로그인 버튼을 눌렀는데 이메일 또는 비밀번호가 일치하지 않는다는 문구가 나와요”처럼 화면, 행동, 오류 문구를 함께 적어 주세요.

## 질문을 잘 작성하는 방법

질문에는 어떤 화면에서, 어떤 버튼이나 링크를 눌렀는지, 어떤 오류 문구가 보였는지, 다시 시도했을 때도 같은 문제가 반복되는지를 포함하면 좋습니다.

계정 문제는 이메일 주소 전체나 비밀번호를 채팅에 적지 말고, “로그인 화면”, “회원가입 화면”, “비밀번호 재설정 화면”처럼 화면 이름과 오류 문구만 공유해 주세요.

Steam 문제는 Steam 로그인 단계에서 실패했는지, GEMBTI로 돌아온 뒤 실패했는지, Steam 라이브러리가 비공개인지, 동기화할 게임이 없다는 안내가 나왔는지 구분해서 적어 주세요.

설문 문제는 문항이 보이지 않는지, 선택지가 눌리지 않는지, 제출 버튼을 눌러도 넘어가지 않는지, 설문 결과 화면이 보이지 않는지 구분해서 적어 주세요.

추천 문제는 설문을 먼저 완료했는지, 추천 생성 화면인지 최신 추천 결과 화면인지, 할인·평점·인기 추천 중 어떤 화면인지 적어 주세요.

## 민감정보를 적으면 안 되는 이유

고객센터 챗봇에는 비밀번호, 인증번호, 액세스 토큰, 리프레시 토큰, API 키, 결제 정보 같은 민감정보를 적지 마세요.

사용자가 민감정보를 적더라도 챗봇 답변에서 그 값을 다시 반복하지 않는 것이 안전합니다.

문제 해결에 필요한 정보는 화면 이름, 발생 단계, 오류 문구, 브라우저 환경, 네트워크 변경 여부처럼 공유해도 되는 범위로 제한해 주세요.

## 문제가 계속될 때 고객센터에 전달할 정보

문제가 계속되면 어떤 화면에서 문제가 생겼는지, 어떤 작업을 했는지, 표시된 오류 문구가 무엇인지, 새로고침이나 재로그인 후에도 같은 문제가 반복되는지 정리해 고객센터에 전달해 주세요.

가능하다면 브라우저 종류, 모바일 또는 데스크톱 환경, Steam 연동 여부, 설문 완료 여부처럼 문제 재현에 도움이 되는 비민감 정보를 함께 전달해 주세요.

고객센터에 전달할 때도 비밀번호, 인증번호, 토큰, 결제 정보 같은 민감정보는 포함하지 마세요.
