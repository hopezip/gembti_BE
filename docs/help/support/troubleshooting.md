# 문제 해결 및 오류 안내

## 문제가 생겼을 때 먼저 확인할 것

GEMBTI 이용 중 문제가 생기면 먼저 어떤 화면에서 문제가 발생했는지 확인해 주세요.

“안 돼요”, “안 떠요”, “안 보여요”, “오류가 나요”, “계속 실패해요”처럼 범위가 넓은 질문에는 화면 이름, 눌렀던 버튼, 표시된 오류 문구, 다시 시도해도 반복되는지를 함께 알려 달라고 안내할 수 있습니다.

대부분의 문제는 로그인 상태, 입력값 형식, 필수 절차 완료 여부, 네트워크 상태, 브라우저 세션 상태를 확인하면서 좁혀 볼 수 있습니다.

새로고침, 재로그인, 다른 브라우저, 다른 네트워크 환경에서 다시 시도하면 일시적인 세션 또는 네트워크 문제를 구분하는 데 도움이 됩니다.

비밀번호, 인증번호, 액세스 토큰, 리프레시 토큰, API 키, 결제 정보 같은 민감정보는 고객센터 챗봇이나 문의 내용에 적지 마세요.

## 로그인 또는 인증 오류

“로그인이 안 돼요”, “인증이 필요합니다”, “로그인했는데 다시 로그인하래요” 같은 질문에는 먼저 로그인 상태와 입력한 계정 정보를 확인하라고 안내할 수 있습니다.

이메일과 비밀번호에 앞뒤 공백이 들어가지 않았는지 확인해 주세요.

회원가입을 완료하지 않았거나 이메일 인증을 마치지 않았다면 먼저 가입과 인증 절차를 끝내야 합니다.

로그인 상태가 만료되었거나 브라우저 세션이 꼬인 경우에는 새로고침 후 다시 로그인해 보세요.

“인증이 필요합니다”라는 문구는 해당 기능이 로그인한 사용자에게만 제공된다는 의미입니다. 내 정보, 설문 제출, 추천 생성, 최신 추천 조회, 고객센터 챗봇 같은 일부 기능은 로그인 후 이용해야 합니다.

반복해서 인증 오류가 나면 브라우저 쿠키를 정리하거나 다른 브라우저에서 다시 시도해 보고, 그래도 계속되면 발생 화면과 오류 문구를 고객센터에 전달해 주세요.

## 회원가입과 이메일 인증 문제

“회원가입이 안 돼요”, “인증번호가 안 와요”, “이메일 인증이 실패해요” 같은 질문에는 이메일 주소, 인증번호 형식, 요청 횟수, 스팸함을 확인하라고 안내할 수 있습니다.

이메일 인증번호는 6자리 숫자 형식입니다. 공백이나 하이픈 없이 숫자만 입력해 주세요.

메일이 오지 않으면 입력한 이메일 주소가 정확한지 확인하고, 스팸함이나 프로모션함도 함께 확인해 주세요.

짧은 시간 안에 인증번호 요청을 여러 번 반복하면 요청 제한으로 잠시 후 다시 시도해야 할 수 있습니다.

이미 사용 중인 이메일이나 닉네임이면 회원가입이 실패할 수 있습니다.

비밀번호는 영문, 숫자, 특수문자를 포함한 10자 이상 100자 이하 형식이어야 하며, 비밀번호 확인 값과 같아야 합니다.

## Steam 연동 문제

“Steam 연동이 안 돼요”, “Steam 로그인 후 돌아왔는데 실패해요”, “Steam 게임이 안 보여요” 같은 질문에는 Steam 로그인 단계와 GEMBTI 복귀 이후 단계를 나누어 확인하라고 안내할 수 있습니다.

Steam 로그인 화면에서 실패했다면 Steam 계정 정보나 Steam 로그인 상태를 먼저 확인해야 합니다.

Steam 로그인은 성공했지만 GEMBTI에서 연동되지 않았다면 브라우저 새로고침 후 다시 시도하거나, 같은 계정으로 다시 연결해 보세요.

Steam 라이브러리가 비공개이면 보유 게임이나 플레이 시간 정보를 가져오지 못할 수 있습니다.

Steam 라이브러리에 공개된 게임이 없거나 플레이 기록이 부족하면 동기화할 정보가 적게 보일 수 있습니다.

Steam 연동은 선택 단계입니다. Steam 연동이 되지 않아도 로그인 후 폼형 성향 설문은 진행할 수 있습니다.

## 설문 제출 문제

“설문 제출이 안 돼요”, “설문 조사가 안 보여요”, “문항 선택이 안 돼요” 같은 질문에는 로그인 상태와 모든 문항 응답 여부를 먼저 확인하라고 안내할 수 있습니다.

표준 성향 설문은 화면에 표시된 폼에서 문항별 선택지를 고르는 방식으로 진행합니다.

모든 필수 문항에 응답하지 않으면 제출이 막힐 수 있습니다.

선택지가 눌리지 않거나 화면이 멈춘 것처럼 보이면 새로고침 후 다시 시도해 보세요.

제출 후 결과 화면으로 넘어가지 않으면 네트워크 상태를 확인하고, 다시 로그인한 뒤 설문 상태를 확인해 주세요.

같은 문제가 반복되면 몇 번째 문항에서 멈췄는지, 어떤 선택지를 눌렀는지, 제출 버튼을 눌렀을 때 어떤 문구가 나왔는지 고객센터에 전달해 주세요.

## 추천 결과 문제

“추천이 안 보여요”, “추천이 안 나와요”, “추천 기록 없음이 떠요” 같은 질문에는 로그인, 설문 완료, 추천 생성 여부를 차례로 확인하라고 안내할 수 있습니다.

추천 생성에는 최신 성향 스탯이 필요합니다. “성향 스탯이 없습니다. 설문을 먼저 완료해 주세요.”라는 문구가 나오면 먼저 표준 성향 설문을 제출해야 합니다.

“추천 기록 없음”은 최신 추천 결과가 없다는 뜻입니다. 추천 생성 기능을 먼저 실행해 주세요.

“세일 중인 맞춤 게임 없음”, “평가가 좋은 맞춤 게임 없음”, “맞춤 인기 게임 없음”은 최신 추천 결과 안에서 해당 조건을 만족하는 게임이 없다는 뜻일 수 있습니다.

“추천 가능한 게임 데이터가 없습니다.”는 사용자가 직접 해결하기 어려운 데이터 상태일 수 있으므로 화면과 오류 문구를 고객센터에 전달해 주세요.

추천 결과가 기대와 다르면 설문 응답이 현재 취향을 잘 반영했는지 확인하고, 설문을 다시 완료한 뒤 추천을 새로 생성해 볼 수 있습니다.

## 게임 검색 및 상세 화면 문제

“게임 검색이 안 돼요”, “게임이 안 나와요”, “상세 화면이 안 열려요” 같은 질문에는 검색어, 필터, 정렬 기준, 게임 상세 진입 경로를 확인하라고 안내할 수 있습니다.

검색 결과가 없으면 오타를 줄이고, 한글과 영문 표기를 바꿔 보고, 장르나 플레이 방식 필터를 잠시 해제해 보세요.

여러 필터를 동시에 선택하면 결과가 너무 좁아질 수 있습니다.

게임 상세 화면이 열리지 않으면 검색 결과에서 다른 게임 상세가 열리는지 확인해 주세요.

특정 게임만 상세 화면이 열리지 않으면 해당 게임 제목이나 게임 ID, 발생 화면, 표시된 오류 문구를 고객센터에 전달해 주세요.

가격, 할인율, 평점, 출시일 같은 정보가 예상과 다르면 Steam 원본 정보와 서비스 데이터 갱신 시점이 다를 수 있습니다.

## 오류 문구별 확인 방법

“인증이 필요합니다”는 로그인해야 이용할 수 있는 기능이라는 뜻입니다. 다시 로그인한 뒤 같은 화면을 열어 주세요.

“요청 형식이 올바르지 않습니다”는 입력값이나 요청 조건이 화면에서 요구하는 형식과 맞지 않을 때 보일 수 있습니다. 필수 입력값, 선택지, 숫자 범위, 페이지 이동 상태를 확인해 주세요.

“서버 내부 오류”는 사용자가 입력을 고쳐도 바로 해결되지 않을 수 있는 서버 측 문제입니다. 같은 문제가 반복되면 발생 시간, 화면, 오류 문구를 고객센터에 전달해 주세요.

“추천 기록 없음”은 추천 결과가 아직 만들어지지 않았거나 최신 추천 기록을 찾을 수 없다는 뜻입니다. 추천 생성 기능을 실행해 주세요.

“성향 스탯이 없습니다. 설문을 먼저 완료해 주세요.”는 추천 생성 전에 표준 성향 설문을 완료해야 한다는 뜻입니다.

“세일 중인 맞춤 게임 없음”, “평가가 좋은 맞춤 게임 없음”, “맞춤 인기 게임 없음”은 추천 결과 안에 해당 조건의 게임이 없을 때 보일 수 있습니다.

## 고객센터에 전달할 정보

문제가 반복되면 고객센터에 화면 이름, 발생 단계, 눌렀던 버튼, 표시된 오류 문구를 전달해 주세요.

로그인 문제라면 로그인 화면인지, 회원가입 화면인지, 비밀번호 재설정 화면인지 구분해 주세요.

Steam 문제라면 Steam 로그인 단계에서 실패했는지, GEMBTI로 돌아온 뒤 실패했는지, 라이브러리 공개 설정을 확인했는지 알려 주세요.

설문 문제라면 문항이 보이지 않는지, 선택지가 눌리지 않는지, 제출 버튼을 눌러도 넘어가지 않는지 구분해 주세요.

추천 문제라면 추천 생성 화면인지, 최신 추천 결과 화면인지, 세일·평점·인기 추천 화면인지 알려 주세요.

게임 검색 문제라면 검색어, 선택한 장르와 플레이 방식 필터, 정렬 기준, 문제가 발생한 게임 제목을 알려 주세요.

## 민감정보를 보내지 않는 기준

고객센터 챗봇이나 문의 내용에는 비밀번호를 적지 마세요.

이메일 인증번호, 비밀번호 재설정 인증번호, 액세스 토큰, 리프레시 토큰, API 키, 결제 정보도 보내지 마세요.

문제 해결에 이메일 식별이 꼭 필요하더라도 고객센터 안내에 따라 안전한 방식으로 전달해야 하며, 공개 채팅창에 전체 민감정보를 적는 것은 피해야 합니다.

오류 문구, 화면 이름, 브라우저 종류, 모바일 또는 데스크톱 여부, 발생 시간, 재시도 여부는 공유해도 되는 문제 해결 정보입니다.

사용자가 민감정보를 실수로 입력했다면 같은 값을 다시 인용하지 말고, 민감정보를 제거한 뒤 문제 상황만 다시 설명해 주세요.

## 반복되는 문제를 줄이는 방법

계정과 추천 기능을 이용할 때는 먼저 로그인 상태를 확인해 주세요.

추천 기능을 이용하기 전에는 표준 성향 설문을 완료했는지 확인해 주세요.

Steam 연동을 이용한다면 Steam 라이브러리 공개 상태와 GEMBTI 연동 상태를 함께 확인해 주세요.

게임 검색 결과가 적으면 검색어를 줄이고 필터를 단계적으로 적용해 주세요.

오류가 반복될 때는 같은 작업을 무한히 다시 시도하기보다 오류 문구와 발생 조건을 기록해 고객센터에 전달하는 것이 더 빠를 수 있습니다.
